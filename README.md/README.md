# 📦 Agiliza Estoque

Agiliza Estoque é um sistema de **gerenciamento de estoque** desenvolvido para facilitar o controle de produtos, entradas e saídas em pequenos negócios.

O sistema permite registrar produtos, acompanhar quantidades disponíveis e manter um controle organizado do estoque através de um banco de dados.

---

## 🚀 Tecnologias utilizadas

- JavaScript
- Node.js
- Express
- MySQL
- HTML
- CSS

---

## 📌 Funcionalidades

- Cadastro de produtos
- Registro de entrada de produtos no estoque
- Registro de saída de produtos
- Atualização automática da quantidade disponível
- Armazenamento das informações em banco de dados

---

## ⚙️ Como executar o projeto

Clone o repositório

git clone https://github.com/Salesalex05/agiliza-estoque

---

Entre na pasta do projeto

cd agiliza-estoque

---

Instale as dependências

npm install

---

Configure o banco de dados MySQL.

Depois inicie o servidor

node server.js
